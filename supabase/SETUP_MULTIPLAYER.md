# Запуск общего приложения «ПОЛЕ» — регистрация, игры, отзывы и поиск команды

Код браузера и SQL-структура добавлены в репозиторий. **Пока `supabase-config.js` содержит пустые значения, приложение остаётся локальным демо**. Код сам по себе не создаёт облачную базу.

## Что необходимо сделать владельцу проекта

1. Создать проект на https://supabase.com/dashboard в своём аккаунте.
2. Открыть **SQL Editor** и выполнить по порядку:
   - `supabase/schema.sql` — авторизация, анкеты, политики доступа;
   - `supabase/community.sql` — игры, участники, поиск команды, отзывы и модераторы.
3. **Authentication → URL Configuration**: установить Site URL `https://krasikovaanna1303-afk.github.io/myfootballapp/`, указать тот же URL как Redirect URL.
4. **Authentication → Providers → Email**: включить Email и подтверждение адреса. Настроить доставку писем для публичного запуска.
5. В **Project Settings → API** скопировать **Project URL** и **publishable (или legacy anon) key**; вставить их в `supabase-config.js`:
   `window.POLE_SUPABASE = { url: "https://PROJECT.supabase.co", anonKey: "PUBLISHABLE_KEY" };`
   **Никогда не публиковать service_role, secret key, пароль базы и JWT signing secret.**
6. Сохранить изменения на GitHub (ветка `main`). Дождаться успешного **Publish football app** в Actions.
7. Зарегистрировать **два разных тестовых аккаунта в двух браузерах**. Создать матч первым, присоединиться вторым и проверить обновление количества участников. После этого проверить поиск команды, отзыв и его статус.

## Модерация

Каждый отзыв или предложение по площадке сначала записывается в `pole_field_feedback` со статусом `pending`. Только одобренные записи доступны всем.

Чтобы назначить модератора, после его регистрации найдите UUID пользователя в **Authentication → Users**. В доверенном Supabase SQL Editor выполните:

```sql
insert into public.pole_moderators(user_id)
values ('UUID-ЗАРЕГИСТРИРОВАННОГО-АККАУНТА')
on conflict do nothing;
```

После следующего входа в раздел «Команды и турниры» модератор увидит кнопку «Модерация отзывов». Обычный пользователь не может самостоятельно назначить себя модератором.

## Что делает реализация

- Общие матчи и запись на них, атомарная проверка свободных мест через SQL-функцию.
- Публикация анкет поиска команды и набора игроков, общая для всех устройств.
- Профили и вход в аккаунты через Supabase Auth, собственные анкеты защищены RLS.
- Отзывы и изменения характеристик полей со статусом `pending`, ручное одобрение модератором.
- Обновление данных при возвращении на вкладку и примерно раз в 30 секунд, без обещаний мгновенных push-уведомлений.

## Ограничения перед широким запуском

- Без облачного проекта Supabase код работает только в демонстрационном режиме.
- Данные, ранее сохранённые в localStorage, **не переносятся автоматически** в новую базу.
- Подготовленная система нуждается в проверке на реальном проекте Supabase, в том числе политик RLS и многопользовательских сценариев.
- Для публичного сервиса необходимы пользовательское соглашение, политика конфиденциальности, жалобы на материалы, удаление профиля, антиспам и резервное копирование.
- Отзывы после одобрения отображаются как проверенные модератором материалы сообщества; это не независимая экспертиза фактического состояния площадки.
- Платёжные функции и получение партнёрских заявок остаются отдельным направлением.
