# «ПОЛЕ»: бесплатный адрес без личного GitHub-логина

В текущем проекте все исходные HTML/CSS/JS-файлы уже лежат в корне GitHub-репозитория. Для Vercel сборка не нужна.

## 1. Создать бесплатный адрес

1. Открыть https://vercel.com/new и войти через GitHub.
2. Импортировать **krasikovaanna1303-afk/myfootballapp**.
3. Название проекта: например, **pole-football**, если свободно. Никакой адрес нельзя считать закреплённым до завершения публикации.
4. **Framework Preset: Other**. **Root Directory: ./**. **Build Command: пусто**. **Output Directory: .** (корень проекта; можно оставить стандартное значение для Other, если папки public нет).
5. Нажать **Deploy**. Проверить, что открывается главная страница, работают карта, вкладки и форма входа.
6. Vercel подключит автоматическую публикацию будущих коммитов из GitHub.

> GitHub Pages может продолжать работать параллельно. Не удаляй прежний репозиторий и Supabase.

## 2. Перенастроить Supabase Auth после получения реального адреса

Когда ВЕРСЕЛЬ ПОКАЖЕТ настоящий адрес (например, https://pole-football.vercel.app/, только если именно такой выделен):

1. Supabase → **Authentication → URL Configuration**.
2. В **Redirect URLs** добавить точный новый адрес с `/` на конце, например `https://<реальный-адрес>.vercel.app/`. Прежнюю ссылку GitHub Pages временно оставить в списке.
3. В **Site URL** указать новый *проверенный рабочий* адрес.
4. Проверить регистрацию и переход из письма подтверждения на новом домене. При изменённых email-шаблонах проверить, что они используют адрес перенаправления, а не жёстко прошитую ссылку.
5. Уже существующие пользователи остаются в той же базе Supabase и смогут войти со своими прежними логинами. При переходе на новый домен браузер может попросить войти повторно, так как сеанс старого домена не переносится.

В `enhancements.js` URL для подтверждения регистрации и повторного письма строится от текущего адреса сайта, поэтому жёсткой привязки к GitHub Pages больше нет.

## 3. Если нужна помощь прямо в ChatGPT

Подключи приложение Vercel в ChatGPT (если доступно) или сделай первичный импорт проекта на vercel.com/new и пришли полученный адрес. После этого можно проверить настройки перенаправлений.

## 4. Отдельная миграция объявлений и платных турниров

Новый рабочий адрес сайта и изменение домена **не заменяют** SQL-миграцию. Чтобы заработали редактирование/удаление объявлений, приватные заявки и ограничение самостоятельной публикации турниров, выполни в Supabase SQL Editor файл:

`supabase/tournament-partnership-and-post-management.sql`

До выполнения миграции новый интерфейс может показывать кнопки, но база не даст редактировать записи, а защита от прямой публикации турниров на уровне SQL ещё не вступит в силу.
