# ПОЛЕ ⚽ — приложение для совместной игры в футбол

Адрес после успешной публикации GitHub Pages: https://krasikovaanna1303-afk.github.io/myfootballapp/

## Что доступно в текущем MVP

- Карта России: выбор из 22 городов и посёлков, поиск других населённых пунктов через GeoNames/Open-Meteo и OSM Nominatim.
- Площадки: поиск футбольных объектов OpenStreetMap в видимой области карты. Исходный каталог содержит шесть конкретных объектов с адресами и ссылками на источники в пяти городах; ориентировочные координаты требуют уточнения.
- Приоритет бесплатных: сначала показываются объекты, отмеченные в данных OSM как бесплатные и доступные, либо указанные пользователями как бесплатные. Если сведений об оплате нет, статус «доступ неизвестен». OSM-отметка и запись пользователя не являются независимой проверкой фактической доступности.
- Футбольная анкета: никнейм, возраст (16+), необязательный пол, уровень игры, позиция, город, формат футбола и интерес к выездам.
- При подключённом Supabase — email-регистрация и вход через Supabase Auth; без него только локальная демо-анкета без паролей.
- Игры, поездки, пользовательские площадки и отзывы работают пока в демонстрационном режиме с сохранением в браузере.

## Ограничения

Даже при подключённом Supabase Auth игры и участники пока не синхронизируются между разными телефонами. Нет реального бронирования аренды, платежей, самостоятельной проверки каждой площадки, модерации. OSM не гарантирует права свободно играть на поле или точности покрытия/разметки.

Приложение загружает OSM-площадки только вокруг видимой области карты; при удалении карты запрос нужно сузить, приблизив её. Публичные серверы Overpass ограничивают нагрузку.

Данные Яндекс.Карт не переносятся в каталог: использование и хранение данных их API регулируется отдельными условиями.

## Публикация

В GitHub открой Settings → Pages → Build and deployment → GitHub Actions. Проверь работу workflow Publish football app на вкладке Actions. Когда развертывание завершится успешно, сайт откроется по адресу выше и по ранее созданному QR-коду.

## Как активировать регистрацию

1. Создай проект в Supabase.
2. Выполни SQL-файл supabase/schema.sql через Supabase SQL Editor (таблица профилей, защита RLS и автоматическое создание анкеты).
3. В Authentication настрой email-подтверждение и URL опубликованного сайта.
4. В supabase-config.js вставь URL проекта и только публичный publishable/anon key. Никогда не добавляй секретный service_role key.
5. Опубликуй изменения и проверь регистрацию, письмо и вход.
6. Для настоящего многопользовательского приложения отдельно предстоит подключить общие таблицы полей, игр, участников и выездов.

Подготовь политику обработки персональных данных, жалобы, удаление аккаунта и модерацию до приглашения широкого круга игроков. Возраст и пол не должны быть публичными по умолчанию.
