# Касание

Футбольное сообщество для Москвы и Санкт-Петербурга. Каталог площадок, встречи с ограничением участников и футбольные выезды в небольшие города.

## Запуск

Нужен **Node.js 24 или новее**: приложение использует встроенный `node:sqlite`.

```bash
npm ci
npm run dev
```

Приложение и API работают на одном сервере, порт по умолчанию — `3000`. В облачной среде используйте `npm ci --cache /workspace/.npm-cache`, если домашняя директория недоступна для записи.

Для сборки и запуска готовой версии:

```bash
npm run build
npm start
```

Переменные: `PORT` (по умолчанию `3000`), `DATABASE_PATH` (по умолчанию `./data/kasanie.sqlite`). Секреты и внешние сервисы для базового запуска не нужны. Изображения и шрифт хранятся локально. Фоновая карта загружается с `tile.openstreetmap.org`; адреса также открываются в Яндекс Картах. При отсутствии доступа к тайлам показывается уведомление, координатные метки остаются доступны.

## Что работает

- Регистрация и вход по email и паролю; пароли хешируются через scrypt, сессии используют случайные токены и HttpOnly cookie. Есть ограничение частоты попыток входа.
- Каталог по городам, поиск по названию / адресу / району, фильтры по цене, освещению, раздевалкам, покрытию и формату.
- Карточки полей, интерактивная карта, избранное и отзывы. Один актуальный отзыв от каждого пользователя на поле.
- Добавление поля с адресом, координатами, характеристиками, стоимостью и описанием.
- Создание игры: время МСК, площадка, продолжительность, уровень, взнос, общая вместимость и размер своей группы, **включая организатора**.
- Присоединение одному или с друзьями, проверка свободных мест, выход из встречи и отмена организатором. «Мои игры» показывает встречи и поездки пользователя.
- Создание и участие в выездах: пункт назначения, дата, бюджет, группа и план маршрута.
- Адаптивная мобильная версия, доступные диалоги с управлением фокусом и закрытием по Escape.

Данные сохраняются в SQLite между перезапусками. База и установленные зависимости исключены из Git. Снимки среды должны сохранять каталог `data/`; при развёртывании на внешнем сервере используйте постоянный диск и резервные копии.

## Проверка

```bash
npm test
npm run test:e2e
```

Серверные интеграционные тесты проверяют авторизацию, отзывы, избранное, добавление поля, групповые заявки, одновременное занятие последних мест, отмену организатором, выезды и сохранение данных после повторного открытия базы.

Браузерные тесты используют Playwright и Chromium. На этой машине браузер находится в `/usr/bin/chromium`; на другой можно задать `PLAYWRIGHT_CHROMIUM_EXECUTABLE` или установить браузер командой `npx playwright install chromium`. Тесты работают с отдельной базой в памяти и не меняют пользовательские данные.

## Данные и границы первой версии

При первом запуске создаются **12 демонстрационных полей**, игры, поездки и отзывы. Это примеры интерфейса, а не полный или проверенный каталог площадок городов. Адреса, координаты, доступность, характеристики и цены демо необходимо сверить перед реальным использованием. Все демонстрационные записи отмечены; иллюстрации сгенерированы и не являются фотографиями конкретных площадок. Пользователи могут добавлять настоящие поля и встречи.

Создание встречи **не бронирует площадку** и не принимает оплату. Организатор должен договориться с владельцем отдельно. В этой версии нет восстановления пароля, подтверждения email, чата, модерации и автоматического импорта полного каталога. Эти функции и верификация площадок — следующие этапы развития.

## Устройство

React 19 + Vite, Express 5, встроенная SQLite, Leaflet, Lucide. `src/` — интерфейс; `server/` — API, база и интеграционные тесты; `scripts/smoke.mjs` — браузерные сценарии; `public/` — локальные ресурсы. Шрифт Manrope распространяется по SIL Open Font License, текст лицензии — `public/fonts/OFL-Manrope.txt`.

## Публикация сайта

Для внешнего HTTPS-адреса подготовлены Docker-контейнер, `compose.yaml` для сервера с постоянной базой и `render.yaml` для бесплатного пробного запуска. Полная инструкция и ограничения бесплатного хостинга — в [DEPLOY.md](DEPLOY.md). Публичный сервис нужно отдельно создать в аккаунте выбранного хостинга.
