# ПОЛЕ ⚽

Мобильное веб-приложение для поиска футбольных площадок, организации матчей и футбольных выездов.

## Демо-возможности
- Интерактивная карта Leaflet + OpenStreetMap, загрузка футбольных объектов через Overpass (покрытие и точность зависят от OSM).
- Поиск и фильтр площадок, своё поле с характеристиками, отзывами и геолокацией.
- Локальный профиль, создание матчей и присоединение к ним, ограничения по местам, отмена участия.
- Футбольные поездки в города и сёла, набор участников.
- Адаптивный дизайн, установка как веб-приложения через manifest.

**Ограничение:** данные сохраняются в localStorage конкретного браузера. У других пользователей они НЕ появляются; это прототип, не полноценная мультипользовательская версия. Регистрация и бронирование платных полей не подключены. Данные OpenStreetMap не гарантируют свободный доступ к полю. Геолокация требует разрешения браузера.

## Публикация по QR
В репозитории есть GitHub Actions workflow `.github/workflows/pages.yml`.
В GitHub открыть **Settings → Pages → Build and deployment → Source: GitHub Actions**, затем Actions → Publish football app → Run workflow (или новый push).
После успешного развёртывания адрес: https://krasikovaanna1303-afk.github.io/myfootballapp/
