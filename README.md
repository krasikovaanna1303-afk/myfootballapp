# ПОЛЕ ⚽ — приложение для совместной игры в футбол

Адрес после успешной публикации GitHub Pages: https://krasikovaanna1303-afk.github.io/myfootballapp/

## Что доступно в текущем MVP

- Карта России: выбор из 22 городов и посёлков, поиск других населённых пунктов через GeoNames/Open-Meteo и OSM Nominatim.
- Площадки: расширенная загрузка OpenStreetMap для выбранной области России — футбольные поля, мини-футбольные объекты, а также универсальные и дворовые спортплощадки с неуказанным видом спорта (последние всегда маркируются как неподтверждённые для футбола). Исходный каталог содержит девять конкретных объектов с источниками, но **не ограничивает количество точек на карте**. Реальное число загруженных объектов зависит от OSM, масштаба, доступности Overpass и фильтров.
- Бесплатные вверху списка. `fee=no` с подтверждающей отметкой публичного доступа в OSM показывается как «бесплатно по данным OSM»; если OSM указывает только отсутствие платы, приложение отдельно предупреждает, что проход не подтверждён. Объекты с неизвестными условиями не считаются бесплатными автоматически; `access=private` — ограниченный доступ. Данные должны проверяться перед игрой.
- Добавлены группировка маркеров для плотной застройки, резервные серверы Overpass, повторный запрос вручную и локальный кэш ранее загруженных меток на срок до 7 дней. Для всех городов используется единая логика, не только для Петербурга.
- В Петербурге доступен внешний государственный [реестр внутридворовых площадок](https://classif.gov.spb.ru/irsi/7814348015-Vnutridvorovye-sportivnye-ploshadki-SPb/structure_version/579/) и [бот «Спорт во дворе»](https://t.me/spb_dvor_sportbot). **Этот реестр не импортирован в приложение:** веб-доступ к прямой выгрузке не удалось подтвердить.
- Футбольная анкета: никнейм, возраст (16+), необязательный пол, уровень игры, позиция, город, формат футбола и интерес к выездам.
- При подключённом Supabase — email-регистрация и вход через Supabase Auth; без него только локальная демо-анкета без паролей.
- Игры, поездки, пользовательские площадки и отзывы работают пока в демонстрационном режиме с сохранением в браузере.

## Ограничения

Даже при подключённом Supabase Auth игры и участники пока не синхронизируются между разными телефонами. Нет реального бронирования аренды, платежей, самостоятельной проверки каждой площадки, модерации. OSM не гарантирует права свободно играть на поле или точности покрытия/разметки.

Приложение загружает OSM-площадки вокруг видимой области карты, с запасом для перемещения. На малых масштабах (вся страна) необходим поиск города/посёлка и приближение: выполнять запрос по всей России через публичный Overpass нельзя. Есть лимит примерно до 5000 объектов на один запрос, поэтому на очень плотных участках рекомендуется приближать карту. У разных серверов разная надёжность и возможны ограничения, а кэш сохраняет ранее загруженные метки. Вкладка может показывать площадки для иных видов спорта, если в OSM указано только `leisure=pitch` и отсутствует вид спорта; это **кандидаты**, а не подтверждённые футбольные поля. Отключи опцию «Универсальные и дворовые» для более строгого поиска.

Данные Яндекс.Карт не переносятся в каталог: использование и хранение данных их API регулируется отдельными условиями.

## Публикация

В GitHub открой Settings → Pages → Build and deployment → GitHub Actions. Проверь работу workflow Publish football app на вкладке Actions. Когда развертывание завершится успешно, сайт откроется по адресу выше и по ранее созданному QR-коду.

## Как активировать регистрацию

1. Создай проект в Supabase.
2. Выполни SQL-файл supabase/schema.sql через Supabase SQL Editor (таблица профилей, защита RLS и автоматическое создание анкеты).
3. В Authentication настрой email-подтверждение и URL опубликованного сайта.
4. В supabase-config.js вставь URL проекта и только публичный publishable/anon key. Никогда не добавляй секретный service_role key.
5. Опубликуй изменения и проверь регистрацию, письмо и вход.
6. Для настоящего многопользовательского приложения отдельно предстоит подключить общие таблицы полей, игр, участников и выездов.

Подготовь политику обработки персональных данных, жалобы, удаление аккаунта и модерацию до приглашения широкого круга игроков. Возраст и пол не должны быть публичными по умолчанию.
