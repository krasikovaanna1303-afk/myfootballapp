⚽ ПОЛЕ · ключи для фоновых push

Этот инструмент создаёт ключи прямо в твоём браузере. Он не отправляет их в интернет и нигде не сохраняет.

Внимание: не выкладывай полученные значения на GitHub и никому их не пересылай. Вставляй их только в Secrets своего проекта Supabase.

1. Ключи VAPID

Supabase → Edge Functions → Secrets → имя POLE_VAPID_JWKS, значение — весь JSON.

2. Секрет для Database Webhook

Используй одно и то же значение для секрета POLE_WEBHOOK_SECRET в Supabase и HTTP-заголовка x-pole-webhook-secret у Database Webhook.
